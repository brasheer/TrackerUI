Additional suggestions 11/2/2026:
TrackerUI Architectural Recommendations & Improvements

1. Dynamic Schema Mapping Configuration
   • Problem: Rigid, fixed column layout dependencies (e.g., Subject to Col A, Tracking ID to Col K).
   • Solution: Implement a configuration panel allowing users to map their own custom Excel column headers to application core fields, scaling the app for different layouts.

2. IndexedDB Local Fail-Safe Cache
   • Problem: Risk of data loss or UI lockups if local directory handles disconnect or freeze during direct file syncs.
   • Solution: Build an offline-first staging buffer using IndexedDB to cache pending mutations locally, allowing a clean flush to the spreadsheet once the file handle recovers.

3. Web Worker-Powered Cross-Tab Searching
   • Problem: Searching historical tabs or large backlogs sequentially can cause main-thread UI performance drops.
   • Solution: Move background Excel parsing and full-history searching tasks into a Web Worker to keep the UI perfectly responsive during massive data lookups.

4. Enhanced Rollover Metadata Tracking
   • Problem: Unfinished requests lose context regarding how long they have been delayed when pushed forward.
   • Solution: Add historical metadata flags during the rollover operation to track an entry's original creation date, giving visibility into chronic backlog items.
